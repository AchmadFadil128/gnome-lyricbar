# LyricBar v0.1.14

Lyric timing control and a GNOME Shell 50 panel-click fix.

## Added

- **Lyrics offset** (Preferences -> Behavior): shift synced lyrics earlier or later to compensate for timing drift between your player and the lyric timestamps. Range `-5000..5000` ms in 50 ms steps; default `0`. Positive values delay the lyrics, negative values show them earlier ([#12](https://github.com/fikrilal/gnome-lyricbar/issues/12)).

## Fixed

- Clicking the panel lyric opens Preferences again on GNOME Shell 50 when the settings icon is hidden. GNOME Shell 50 routes panel-button clicks through a `Clutter.ClickGesture` that consumed the press before the previous signal-based wiring; the indicator now owns its click gesture directly ([#14](https://github.com/fikrilal/gnome-lyricbar/issues/14)).

## Verification

- `npm run verify` and `npm audit` clean on the release commit; CI green on `main`.
- Lyrics offset: unit tests for normalization, offset math, and display shifts; schema range enforcement verified against the compiled bundle schema; module behavior verified under GJS.
- Panel click: root cause and fix approach verified against GNOME Shell 50.1's panel implementation.

## Notes

- The offset is applied at display time, after browser position normalization, so player selection, caching, and lyric lookups are unaffected.
